# Virtual Beep Piano 

This project is a simple virtual piano built using C# and Windows Forms. <br>
The user can play 16 keys, using both form buttons and keyboard keys. <br>
Each key plays a note of a specific frequency, and the sound continues as long as the key is held down.

## Project features:

- Supports playing with both mouse and keyboard.

- Sound playback implemented using Windows API (Beep).

- Simple and clear form with buttons for each note.

- Easily extensible code: new keys and notes can be added.
